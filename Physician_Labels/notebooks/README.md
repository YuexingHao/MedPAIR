# Physician_Labels notebooks

Run these with the Jupyter **working directory** set to **`Physician_Labels`** (repo: `NeuRIPS25/Physician_Labels`), or open the notebook from this `notebooks/` folder.

The first code cell in each notebook switches the process cwd to `Physician_Labels` when it detects `Mar2_2026_Data/` next to or above the current directory, so paths like `results/*.csv` resolve correctly.
